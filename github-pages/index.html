Overview

What is RiskTrace?

RiskTrace scans a GitHub repository, extracts direct and transitive dependencies, matches them against known vulnerability databases, and produces a risk score with actionable recommendations.

Dependency Scanning

Extracts direct and transitive dependencies from any GitHub repository.

Vulnerability Matching

Cross-references dependencies against known vulnerability databases.

Risk Scoring

Produces a quantitative risk score for the overall supply chain.

Actionable Insights

Provides clear recommendations on how to mitigate identified risks.
